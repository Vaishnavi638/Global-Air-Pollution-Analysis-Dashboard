# Global Air Pollution Analysis - ( Excel Dashboard )

Project Overview

This project presents a comprehensive Global Air Pollution Analysis Dashboard built using Microsoft Excel.

The dashboard provides an interactive visualization of air quality data across multiple countries, helping analyze pollution levels, AQI categories, pollutant concentration trends, and country-level comparisons.

The goal of this project is to transform raw environmental data into meaningful insights using Excel’s advanced features like Pivot Tables, Charts, Slicers, and Data Visualization tools.

🎯 Objectives

Analyze global air quality trends

Identify the most polluted countries

Understand AQI category distribution

Compare pollutant concentration levels

Enable interactive country-level filtering
